## 📖 Descripción

El Simulador Integral de Crisis Económica es una aplicación web interactiva que permite analizar diferentes escenarios relacionados con situaciones económicas que afectan a la población.

La plataforma ofrece herramientas para simular:

- Abastecimiento de carburantes.
- Incremento de precios de alimentos.
- Costos adicionales de transporte.
- Compras familiares.
- Rumores de escasez.
- Pérdida del poder adquisitivo.

Cada simulación genera resultados dinámicos, indicadores de riesgo y análisis visuales para facilitar la comprensión de los efectos económicos.

---

## 🎯 Objetivo

Desarrollar una aplicación web interactiva utilizando HTML, CSS, JavaScript y Bootstrap que permita modelar escenarios económicos y mostrar resultados de manera visual y comprensible.

## 🚀 Funcionalidades

### ⛽ Simulador de Abastecimiento de Carburantes

Permite calcular cuántos días durará una reserva considerando:

- Reserva inicial
- Consumo diario
- Reabastecimiento diario
- Nivel crítico

---

### 🛒 Simulador de Precios de Alimentos

Calcula:

- Porcentaje de incremento de precios
- Gasto adicional familiar

---

### 🚌 Simulador de Costos de Transporte

Analiza:

- Distancia adicional por desvíos
- Costos extras generados

---

### 🛍️ Simulador de Compras Familiares

Evalúa:

- Presupuesto disponible
- Exceso o déficit económico

---

### 📦 Simulador de Rumor de Escasez

Permite estimar:

- Incremento de demanda
- Disponibilidad de stock

---

### 💰 Simulador de Poder Adquisitivo

Calcula:

- Variación del poder adquisitivo
- Impacto de los gastos sobre los ingresos

---

## 📈 Sistema de Resultados

Los resultados son mostrados mediante indicadores visuales:

| Estado | Significado |
|----------|-------------|
| 🟢 Positivo | Situación estable |
| 🟠 Alerta | Riesgo moderado |
| 🔴 Crítico | Riesgo elevado |

Además se muestra una barra de riesgo dinámica para facilitar la interpretación de los resultados.

La aplicación incluye casos predefinidos que permiten cargar automáticamente escenarios de prueba para cada simulador.
